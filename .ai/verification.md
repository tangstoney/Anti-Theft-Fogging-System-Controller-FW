## 到板P0步骤

1. 记录板卡编号/PCB/晶振/调试器/COM/跳线；USB-TTL接PB10 TX与GND，115200 8N1。不能把板上J3的USART1误当成当前console。
2. 烧录M4 build/*.hex，起点0x08000000，不写M0或进行全片擦除。
3. 复位应先看到RT-Thread版本，再有BOOT role=... mode=BENCH_ONLY及HEARTBEAT；确认rt_tick_get推进、input/main都被调度，不能只看到一条启动日志便判定RTT正常。
4. PA0稳定按下只一条BENCH_KEY并改变LED，长按不连发，上电按住不产生事件；queue_drop为0。
5. 保存串口日志、镜像SHA256、接线/工具信息；量测线程栈余量、检查heap/MSP边界和断言。

## IMU（QMI8A01z）两条检测链路：本轮验证范围

参数全部在 [inc/project_config.h](../inc/project_config.h)，分“公共采样 / Any-Motion 唤醒 / 运动状态 / 疑似冲击 / 调试日志”五组，均为台架实验值。前一步不通过不进入下一步。

0. 接线与 ID：PB8=SCL、PB9=SDA（4.7k 上拉或模块自带），PC0 接 IMU INT1，3.3V 共地。复位后应看到 `IMU_OK addr=0x6A`；`FAULT imu_init=-2` 是 ID 不匹配（先查 0x6A/0x6B、SDA/SCL 是否接反），`-1` 是总线错误。
1. 采样链路自检（先确认数据是新的、连续的）：
   - 约每秒一行 `IMU_MOTION_STAT`；
   - `n` 稳定在 40~100（100Hz 采样、1 秒窗口；读取与芯片更新重叠时会丢弃整帧，`n` 低于 100 是正常的）；
   - `chip_n/1000` 接近 1000，明显偏小说明芯片实际 ODR 与配置不符或读取被阻塞；
   - `err=0`；`drop` 是丢弃帧数（aDA=0 或一致性复核不通过），静置时应接近 0；
   - `edges` 随扰动增加。
2. 停车静置：`rms` 只有噪声底（预期几十 mg），`state=STILL` 稳定；10 分钟内不出现 `SHOCK`，`VEHICLE_STATE` 不反复跳变。
3. 停车时轻敲/推晃模块（安全幅度）：应出现 `SHOCK ... peak_norm=...mg`，同时观察**下一次** `IMU_MOTION_STAT` 的 `state` 是否仍为 `STILL`——单次冲击不得直接把车辆判成行驶。若确实翻成 `MOVING`，先查 `RD91_MOTION_ENTER_WINDOWS` 是否被改小、冲击样本是否被计入（采样层在冲击事件期间不累加）。
4. 启动并行驶：从开始振动到 `VEHICLE_STATE v1=2` 的延迟应约为 `RD91_MOTION_ENTER_WINDOWS` 秒（当前 2 秒）。
5. 停车：从停稳到 `VEHICLE_STATE v1=1` 的延迟应约为 `RD91_MOTION_EXIT_WINDOWS` 秒（当前 3 秒）。
6. 正常路面接缝/减速带：记录运动状态是否被误判为 `MOVING`，以及 `SHOCK` 事件数量与峰值；这一项决定冲击阈值是否需要提高。
7. 台架抬升/倾斜/反复扰动：记录 `rms`、`SHOCK` 峰值与时长，为后续撬动检测（无大尖峰场景）留基线数据。

验收时同时记录两条链路是否互相干扰：冲击事件期间样本不计入运动统计，所以持续冲击会让窗口样本不足而判 `UNKNOWN`（不是 `STILL`），这是有意设计。

未上板验证项（不得在交付说明中写成已验证）：I2C 从机地址 0x6A/0x6B、400kHz 实际时序与上拉（传输层按厂商 I2C_Master 例程重写，仍须用逻辑分析仪确认 ACK/STOP/重复 START 波形）、PC0 有效电平与上升沿、Any-Motion 阈值字段宽度（手册 "5-bits fraction" 表述）、0.0625g/1样本的实际灵敏度、ODR 与滤波器实际效果、INT1 事件保持时间、10ms 采样对窄冲击峰值的漏采比例、一致性复核的实际丢弃率、全部振动/冲击阈值。

已知限制（本轮明确不解决）：
- 峰值是 10ms 采样点上的最大值，短于一个采样间隔的尖峰可能被漏掉，日志里看不到不代表没有发生；
- 芯片没有 FIFO 读取方案，没有高 g / 冲击专用引擎，Any-Motion 是相邻样本差值；
- `peak_norm` 是含重力的三轴合矢量，**不是**“冲击加速度本身”，不能直接换算成产品指标 0.5g/1.5g/150ms；
- 缓慢撬动/顶起没有大尖峰，疑似冲击链路按设计不会产生事件；
- 停车/行驶是振动推断，不是测速；低速匀速、坡道起步、单次开关车门都可能落在阈值附近。

阈值不是产品指标：`RD91_MOTION_*` 与 `RD91_SHOCK_*` 均未装车标定，本轮只是台架实验值。
